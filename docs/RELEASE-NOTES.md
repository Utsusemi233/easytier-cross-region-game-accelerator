# 源码版本记录

## 未发布：Windows 网关接入的网络变化恢复

新增电脑实际 IP 变化、虚拟 DHCP 与远端端点更新的区分，以及 Wi-Fi/热点切换的路由检查和验收要求。AI 提示词要求同配置重连、按当前网关维护底层绕行并清理自身旧路线。中文介绍、英文说明和代理操作入口同步更新。

新增显式安装的 Windows 后台组件与示例配置，监听本机网络变化、维护自有底层路线，原生网关与 HTTPS 验证通过才恢复所管理路由。它保留官方客户端，适用范围和回退检查见 NETWORK-ROAMING.md。增加隔离的路线规划测试。既有 Release 与备份保持原快照；公开记录不包含所有者的地址、口令或个人测试数据。不同热点、IPv6-only、其他 VPN 和开机恢复仍需分别验收。

## 0.1.3-preview

本版补充官方电脑客户端接入已有 OpenWrt 纠错网关的部署参考。电脑增加原生接入，网关继续使用既有 WireGuard + UDPspeeder 后端；管理员仍需配置新来源的分类、转发/NAT 和生命周期，不宣称安装脚本自动创建这层桥接。

新增自动虚拟 IPv4 的客户端 TOML、网关 TOML 和 nft 表达式参考。修正文档中要求每台电脑手填独立身份/地址的表述：同一 EasyTier 私网共享网络凭据，客户端可由官方程序自动生成本地标识并分配地址，固定地址恢复文件不用于多机同时运行。

[部署问题与处理](DEPLOYMENT-LESSONS.md)按入口、路由、真实游戏 UDP、返程、DNS/IPv6、底层递归和重载恢复组织排查。中文 README、英文说明和 AI 部署入口同步更新。

动态模块的热插拔通知支持配置中的自定义 WAN/WAN6 名称和 ZeroTier `zt*` 设备，保留周期轮询与原出口验证门控。事件通知不会直接把新端点标为可用。

源码兼容性检查通过；12 种隔离的热插拔事件通过；两份 TOML 由官方 2.6.4 程序以 `--check-config` 解析通过，未启动网络。模板解析和事件测试不替代实体设备、真实外出、运营商换前缀、SDK/IPK 构建或应用效果验收。该版本没有新增私人配置、运行日志或个人测速数据。


## 直连出口的增量源码

增加官方 Windows GUI 的本机 UDPspeeder 入口、授权节点公网 IPv6 发现和 ZeroTier IPv4 备用。维护组件监测物理接口/地址/网关与 TUN 地址，按真实出口验证管理选定地区 IPv4 路由。ICMP 丢失时用家庭 DNS/TCP 与绑定源 HTTPS 联合核查，避免仅因 ping 丢失反复撤路由；所有入口失败仍撤下自身路线。

新增逐地址出口监听参考、DHCP TOML、配置模板、分目录手册和隔离测试。旧 OpenWrt/WireGuard 后端与旧 Release 保留。不同热点、真实运营商前缀变化、第二实体电脑、整机启动等需分别实测，未将所有者的私人现场记录公开。
