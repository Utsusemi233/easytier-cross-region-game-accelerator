# 兼容性与部署范围

项目按“接入端”和“授权出口端”组织连接。主要模式在本地 OpenWrt 上统一分流；电脑可以使用独立原生客户端入口。出口的硬件形态取决于所用协议、运行环境与转发配置。

## 当前 OpenWrt 网关脚本

以下为网关脚本针对的接口和参考版本，不是对所有设备的硬件验收承诺。当前自动部署面向 OpenWrt 接入端和 OpenWrt 出口端。

| 角色 | 脚本目标 | 部署要求 |
| --- | --- | --- |
| 访问端 | OpenWrt 衍生固件，fw4/nftables | Lua5.1、LuCI Lua兼容层、WireGuard内核、ip、curl、conntrack |
| 授权出口端 | OpenWrt 衍生固件，fw3/iptables | Lua5.1、TUN、iptables、ip、curl |
| EasyTier | core 2.4.5 参考接口；LuCI 2.6.4 参考代码 | 同时核对 core 与界面版本，不以版本号推断全部参数兼容 |
| UDPspeeder | V2 参考接口 | 匹配 CPU 架构，两端参数一致 |
| 其他架构、客户端fw3、出口fw4 | 需要另行适配 | 部署条件检查未通过时停止，不强装别的固件内核包 |
| 纯IPv4、运营商整体换前缀、多访问端 | 需要独立验证 | 不从局部连通推断长期可用 |

## 电脑接入与其他出口平台

| 部署方式 | 当前范围 | 需另行检查 |
| --- | --- | --- |
| Windows 原生 EasyTier 客户端 | 提供官方 GUI 配置和 AI 操作说明，见[电脑接入说明](WINDOWS-TRAVEL.md) | 匹配的原生出口入口、共享网络凭据、未冲突的自动或固定地址、实际路由与出口、直连或中继、停止与网络切换 |
| 官方电脑客户端接入已有 OpenWrt 纠错网关 | 2.6.4 TOML 与手工集成参考，见[原生网关接入](NATIVE-GATEWAY.md)；安装脚本不自动部署新增桥接 | 原生 TUN 的分类、策略路由、WG源允许范围/源NAT、当地出口、重载恢复；真实新机器与外出单独验收 |
| Windows WireGuard + UDPspeeder | 尚未完成该完整链路的验收 | 纠错运行环境、两端参数、端点维护和游戏效果 |
| Linux 主机或 NAS 授权出口 | 可按平台另行部署服务；仓库尚无对应的自动部署实现或验收结论 | 所选隧道服务、运行权限、公网入口、防火墙、互联网转发/NAT及服务恢复 |

原生电脑入口不自动获得网关模式的 UDPspeeder 纠错；OpenWrt 配对资料也不能直接导入为原生 EasyTier 配置。公网 IPv4 在上级路由器上时需检查 UDP 端口映射；IPv6 接入需检查出口主机自身的全球地址与防火墙。固定公网地址和动态公网地址应分别验证实际恢复行为。

接入已有纠错网关时，家庭端继续使用原协议，电脑新增本地原生接入；不是在 Windows 上再运行一套 UDPspeeder。DHCP 模板共用网络身份，运行时自动取得可用虚拟 IPv4。两个无 TUN 实例的分配检查只验证选址，不能代替实体设备、网络切换或应用体验验收。

上游 LuCI 参考提交：EasyTier/luci-app-easytier `79b2b01ded627a634e4bea8d60c7be0f00b708b0`。当前扩展保留 Lua 控制器与 ES5 页面，不引入额外网页服务。

使用安装脚本清理本扩展自己的 Lua 编译缓存。不同主题、nftables 表达形式、系统库及防火墙版本须在实际设备检查。内存不足时不要叠加新的重型服务。

每次部署都应按[验收方法](ACCEPTANCE.md)记录通过、失败与未执行项目。公开仓库不收录所有者的具体硬件记录、地址或私人测试数据。
