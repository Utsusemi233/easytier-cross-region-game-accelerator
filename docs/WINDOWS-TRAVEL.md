# Windows 电脑独立接入授权出口

电脑可以安装官方 EasyTier 客户端，通过匹配的原生入口独立接入目标地区授权出口，无需经过本地软路由。电脑接家中网络、酒店Wi-Fi、热点或其他网络时，都按本机配置选择流量范围；具体网络条件须单独验证。

本项目的主要模式是在本地 OpenWrt 上统一管理接入网络的流量。本文介绍独立电脑入口，只覆盖该电脑的路由；已有出口可继续使用，但必须提供与电脑客户端匹配的原生监听、网络身份和互联网转发。出口运行在 OpenWrt、Linux 主机或 NAS 上时，应分别检查对应运行环境；仓库当前的自动出口部署仅针对 OpenWrt。

## 两种入口

| 入口 | 使用方式 | 与当前原型的关系 |
| --- | --- | --- |
| 原生EasyTier电脑客户端 | 独立虚拟IPv4、私有网络身份、家庭exit node；共享节点用于发现和必要时中继 | 可选独立入口；没有UDPspeeder纠错，须单独验证 |
| WireGuard与UDPspeeder电脑客户端 | 独立WireGuard密钥/地址、两端一致的纠错参数和地址维护 | 尚未在Windows验收，不把路由器的密钥或地址克隆给电脑 |

共享节点只是发现/中继服务。国内出口来自你自己的、已经允许出口转发的家庭节点；公共共享节点本身不是免费国内互联网出口。

有可达公网地址并开放匹配入口时，可配置电脑直接连接授权出口；实际走直连还是中继需查看 peer 路径。公网地址本身不代表服务已经运行，目标游戏服务器也不承担本项目的隧道出口角色。路由器的 WireGuard 配对 JSON 不能当作原生 EasyTier 配置导入。

## 配置原则

1. 从 EasyTier 官网下载页面进入官方发布页，安装原生 **EasyTier GUI**，校验 Release API 给出的 SHA-256 摘要。将快捷方式直接指向官方 `easytier-gui.exe`，不制作另一个连接界面。参考出口接口为2.4.5；新版与实际出口的兼容性须单独验证。
2. 将程序和私人配置保存到本机目录，私人配置不放GitHub。Windows TUN网卡和系统服务安装需要管理员确认。
3. 家庭端使用独立原生入口或独立实例，避免更换既有路由器游戏隧道的身份。公网IPv6监听和防火墙放行要一致；入口出站连接共享节点，可在地址变化时重新发现。
4. 电脑使用独立instance_id和不冲突的虚拟地址；设置exit_nodes为家庭虚拟IPv4。使用明确的routes决定哪些目标进入TUN，不凭“已加入网络”就认定已加速。
5. 可以按APNIC中国IPv4分配记录生成国内分流网段，保留其他IPv4与IPv6本地走。分配记录只代表地址注册区域，不是应用清单，也不能保证覆盖海外CDN或所有国服目标。不要把普通互联网默认路由替换后忘记排除隧道入口，造成递归。
6. 优先用官方 GUI 的保存、运行、停止和托盘功能；如需开机恢复，使用官方服务模式并单独验收。停止后核对TUN与其路由消失，不删除其他VPN网卡、DNS或路由。

## 必须验证

- 本机虚拟地址唯一，TUN和配置网段真实存在。
- peer/route输出可见授权家庭节点，并区分直连、经中继、断开；不能只检查进程存在。
- 测试流量实际使用EasyTier网卡，家庭转发/NAT有效；对照本地与家庭IPv4公网出口。
- 海外网站及未选定目标保留原出口，系统原DNS和IPv6不被意外关闭。
- 停止/启动后路由释放和恢复有效；本机实际更换网络的测试单独报告。
- 公网IPv6撤下、新前缀、共享节点故障、仅IPv4热点以及游戏内延迟对照，未执行时写“未测试”。

电脑入口需要自己的验收。没有实际测试的酒店、热点、网络切换或IPv4-only条件，应明确记为未执行。
