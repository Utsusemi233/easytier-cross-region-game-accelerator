# 公共学习资源

[VPN Gate 公益 VPN 项目](https://www.vpngate.net/en/) 提供由志愿者维护的公共 VPN 信息，可用于学习 VPN 协议、连接流程和不同出口的工作方式。

**仅作为学习参考。本项目不保证 VPN Gate 的有效性、可用性或安全性，请谨慎使用。** 它是独立第三方项目，不是本项目提供的节点，不会自动加入你的 EasyTier 网络，也不保证有适合目标国家或地区的游戏出口。使用前自行阅读其协议、运营说明和日志政策。

共享组网中继、允许互联网转发的出口、公共 VPN 是不同能力。自己的跨地区方案仍应使用你管理或明确获授权的出口，并验证实际路线。

## English

[VPN Gate](https://www.vpngate.net/en/) is a public volunteer VPN project that can be used to learn about VPN protocols and connections.

**For learning only. This project does not guarantee its effectiveness, availability, or safety. Use it cautiously.** VPN Gate is independent of this project and is not automatically used as an EasyTier peer or an Internet exit. Review the operator's terms and logging policy yourself.
