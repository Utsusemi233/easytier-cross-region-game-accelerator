# 电脑游戏进程分流实验

这个可选实验用于比较两种接入方式：现有官方 EasyTier 客户端，以及本机按游戏进程分流的 sing-box 客户端。目标是让游戏建立的新连接通过已授权的地区出口，其他软件继续使用本地网络。实验不包含在当前自动安装脚本或 LuCI 面板中。

## 连接结构

```text
游戏进程的 IPv4 TCP
  → Windows sing-box TUN / 进程规则
  → Hysteria2 / 已授权私网入口
  → 已有 WireGuard + UDPspeeder 网关后端
  → 授权地区出口

其他进程、游戏 UDP、物理 IPv6
  → 本地网络
```

本文的初始实验范围是 IPv4 TCP，UDP 保持直接联网。扩大范围前须独立验证 UDP 请求与返回。不能把 HTTPS 可用或服务启动成功写成完整游戏加速验收。IPv6 保留原路径；不要为了扩大分流范围关闭 IPv6。

进程规则不依赖预先收集所有游戏服务器 IP。它需要核心正确识别新连接的进程，也需要单独检查启动器、反作弊辅助进程和场景连接。观察到一个 TCP 场景连接，不代表游戏全部报文或显示的延迟都依赖 TCP。已经建立的会话可能继续使用旧地址，切换后应重新登录再测量。

## 准备与隔离

使用上游官方程序，核对版本、平台、发布文件摘要和许可证。客户端参考 sing-box 1.14.3，网关参考已有 sing-box 1.12.1；两端分别检查实际配置解析和数据路径。参考环境使用 Windows PowerShell 5.1 与 fw4 网关。其他版本、内核、防火墙或平台仍需独立验证。

先保存原客户端配置、运行状态和它拥有的路由。为实验使用单独名称、配置目录、TUN、状态目录和服务名。不要更改现有 EasyTier 私网名称，也不要同时启动两套会接管相同目标的加速路线。

网关入口绑定已授权的私网地址。防火墙只添加实验服务拥有的规则，停止时按所有权删除；不需要为这个结构新开公网端口。网关转发绑定已验证的隧道接口和策略源地址。实际出口、返程和 NAT 仍要检查，接口绑定本身不代表可以出网。

在内存较少的 OpenWrt 上先检查可用内存、交换区和存储，优先评估已有程序。不要同时叠加多个传输核心，也不要为一个短期实验强装其他固件的软件包。

## 先验证数据路径，再启用 TUN

1. 在本机仅监听回环地址的诊断代理上验证 TCP HTTPS。至少取得成功的 HTTP 响应与实际响应内容；SOCKS CONNECT 确认消息不能代替远端连接证明。
2. 单独验证 UDP 的请求与返回。DNS 被中继到 HTTPS DNS 时，只能报告这一条 UDP 中继路径，不代表普通互联网 UDP 全部可用。失败时保留失败记录，并将 UDP 排除出实验范围。
3. 每次启动重新运行当前诊断。历史成功回执不能长期代替新检查。
4. 暂停原客户端，等待它拥有的路由撤销，再启动实验 TUN。启动失败时停止实验，恢复原客户端并验证新鲜状态。

TUN 的 IPv4 接管与按进程选择出口是两件事。普通软件也可能经过 TUN 后由 `direct` 出站；应检查其实际出口，不能因为配置有进程规则就声称它们完全没有经过本机核心。排除底层私网目标，并检查自动识别物理出口，防止隧道自身又进入 TUN。

## 游戏对照和恢复

从完整登录开始，核对游戏进程、实际场景连接、TUN 来源地址、出站标签及双向数据。取得真实可游玩的场景后再采样延迟。加载画面、重连画面或启动器连通不能作为有效延迟样本。

同网络、同设备、同服务器和场景下分别记录原方案、实验方案、恢复原方案。记录各次时间、游戏内延迟、断线、服务器是否变化，以及网关负载和后端状态。短期波动不能证明协议普遍更快。

停止实验时只撤销实验核心和实验接口的路由。重新运行原官方客户端后，验证其出口与当前路由；仅发出启动命令不算恢复通过。截图、目标地址、身份和个人测量应放入部署者自己的私人记录。

## 换网边界

客户端配置不应写死电脑的物理 IP。底层私网负责自身连接变化，核心识别当前物理出口，已有网关模块负责后端端点变化。仍须实际测试 Wi-Fi、热点及故障恢复，不能把这种结构描述为任何国家、任何热点都可用，也不能承诺已建立游戏会话始终不断线。此实验尚不具备单独验收的全链路自动回退功能。

## 上游依据

- [sing-box TUN 配置](https://sing-box.sagernet.org/configuration/inbound/tun/)：自动路由、底层排除和接口选择。
- [路由规则](https://sing-box.sagernet.org/configuration/route/rule/)：Windows 进程名称与网络类型匹配。
- [Hysteria2 出站](https://sing-box.sagernet.org/configuration/outbound/hysteria2/)与[入站](https://sing-box.sagernet.org/configuration/inbound/hysteria2/)：协议和版本参数。
- [拨号字段](https://sing-box.sagernet.org/configuration/shared/dial/)与[TLS 配置](https://sing-box.sagernet.org/configuration/shared/tls/)：接口、源地址和证书校验。

这些上游能力为实验提供实现条件。游戏效果与故障恢复需要按上述方法另行验证。
