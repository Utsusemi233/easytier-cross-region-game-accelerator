# 暂停与恢复

先保存当前变更，再按修改归属恢复。保留原固定地址恢复 TOML、旧任务定义、项目路由日志、纠错服务和有名称的防火墙段备份。

1. 暂停加速：官方 GUI 禁用该网络，检查自己的地区路线不再存在。
2. 移除维护组件：管理员运行 `Install-DirectHomeRecovery.ps1 -ConfigPath <私人配置> -Remove`。它只处理对应任务、受记录进程与明确记录的路由，不清空系统路由表。
3. 返回旧模式：先完全停止直连维护，再导入旧官方配置，最后启用对应旧任务。不要让两个任务管理同一 TUN。各模式恢复后须单独验证。
4. 家庭端按自有文件/服务与有名称的防火墙规则撤销新入口；保留旧 WG/FEC、WAN、Wi-Fi、ZeroTier 和其他业务。完整 firewall 备份是比较资料，不盲目覆盖当前设置。
5. 故障测试的临时阻断必须删除。检查项目端口、日志、默认路由、其他网站和原加速线路。

现场人工维护可以临时使用已有通路，但维护转发不是最终加速数据路径；结束时关闭只为维护新增的监听与规则。不要因进程 PID 相同就删除，需核对路径、启动时间和端口归属。
