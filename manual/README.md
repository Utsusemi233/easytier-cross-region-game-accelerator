# 分步操作手册

本手册是现有项目的增补，记录官方 Windows 客户端直连授权出口的配置、动态恢复、规则与验收。OpenWrt 网关原有模式继续使用其部署说明，不需要重新建立整套项目。

按顺序执行，每步保存修改范围、验证和恢复证据：

- [01-home：出口端](01-home/README.md)
- [02-client：官方电脑客户端](02-client/README.md)
- [03-roaming：网络和地址变化](03-roaming/README.md)
- [04-rules：分流规则](04-rules/README.md)
- [05-tests：验收](05-tests/README.md)
- [06-restore：暂停与恢复](06-restore/README.md)
- [07-publish：记录和发布](07-publish/README.md)

公开版不收录真实地址、口令、身份或所有者的测试结果。私人现场手册应引用对应检查文件，并保留原始记录。
