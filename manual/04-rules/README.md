# 分流规则

`prefixes_file` 是选定目的 IPv4 CIDR 的 JSON 数组。地区地址集合能覆盖同一地区的多数新服务器，减少逐个追游戏 IP 的工作；它不是按进程识别，也不能保证所有 CDN、应用域名和 IPv6 都会走该出口。

1. 保留原集合备份，注明来源、获取时间、许可和合并方法。需要增删时先检查网络地址是否规范，不接受 /0 或 /1 作为地区模式规则。
2. 先停止本项目维护任务。修改自己的 CIDR 文件，保留原路由归属日志，再启动任务。新鲜出口验证成功后检查新增路线和已删除路线清理。
3. 使用 Windows 实际路由查询或 IP Helper API 核对目的地址的接口，不能只看配置文本。确认应用的连接源地址、出口端转发/NAT 和返回流量。
4. 新建连接可能才使用新源地址。可显式允许 `reconnect_app_executables` 中的完整程序路径；仅重建这些程序的旧源 IPv4 TCP、且当前目的路线确实属于隧道的连接。其余程序不处理，UDP 会话仍需应用自行重连。
5. 测试未选目标的当地出口和物理 IPv6。网页保存、路线命中和应用加速是三种不同证据。

这里是 Windows 直连组件的规则文件操作。现有 LuCI 面板管理 OpenWrt 网关规则，不声称它会远程自动同步所有电脑配置。
