# 出口端

先只读检查 CPU 架构、固件、fw3/fw4、TUN、全球 IPv6、实际 WAN 设备、可用内存和已有服务。保存本项目将修改的文件与规则；记录恢复路径。不要因为插件界面版本相同就认为内核接口兼容。

1. 用 `examples/direct-home-exit.toml` 填写受授权网络身份、固定虚拟出口地址和原生 UDP 入口。启用加密与系统转发，先用匹配版本 `--check-config` 验证，不输出密钥。
2. 给 UDPspeeder 配对独立纠错口令，让其转发到本机原生 UDP 入口。公网侧逐个绑定当前全球 IPv6；通配绑定可能选择另一源地址回包。另设授权私网 IPv4 入口。
3. 使用 `home-direct/` 的参考文件配置独立 procd 服务。地址监测只重建这条新纠错入口，不重启已有网关、其他网络或旧纠错链路。示例是人工审阅后安装的参考文件，不是全自动出口安装器。
4. 配置虚拟子网到实际 WAN 的转发、源 NAT 和 MSS。根据 fw3/fw4 使用相应持久化接口，仅添加有名称的项目规则。开放虚拟网关的 ICMP 和 DNS 诊断入口，私网入口限授权网络。
5. 检查逐地址监听、原生节点、转发计数、实际返程和防火墙重载后状态。服务存在不表示可出网。

交付记录：固件/架构、二进制来源和摘要、修改清单、规则作用范围、监听读回、出口验证、回退步骤。真实地址、口令和完整备份只放私人资料库。
