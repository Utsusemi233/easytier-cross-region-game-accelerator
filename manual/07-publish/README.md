# 记录和发布

每一步分别写入本手册目录。原始长笔记保留原文，只追加新章节；当前摘要和历史失败文件可以并存，须注明哪些是已修复历史结果。

公开项目只发布通用代码、配置占位符和不含现场资料的部署方法。私人资料库保存真正入口、口令、当前配置、恢复文件、来源摘要和可复核验收记录；发布前后都检查它仍为 PRIVATE。

1. 阅读 `AGENTS.md`，按技术文体审阅叙述。已实现、现场通过和其他环境尚未验证分别表达，不把希望实现的效果写成完成。
2. 运行源代码、PowerShell 解析和隔离逻辑检查。逐项整理现场测试的 PASS/FAIL/SKIPPED；游戏效果需要游戏场景证据。
3. 扫描公开工作树及待发布对象中的地址、密钥、身份、私人截图和测试信息，检查相对链接和脚本换行。备份私密资料也不能打进公共源码包。
4. 检查提交差异、远程仓库名称和可见性。推送后核对远端提交，复查公开内容。
5. 既有 Release 保持原快照。新代码与旧下载包版本不同须写清楚，不把源码更新说成旧包已自动升级。

私人部署包不复制 ZeroTier 的设备私钥，也不承诺没有新设备测试就能普遍部署。
